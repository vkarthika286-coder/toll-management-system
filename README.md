# Toll Management System

## Project Overview

The Toll Management System is a Python and MySQL based project designed to manage toll-related services.

The system calculates toll costs based on vehicle type, distance travelled and the selected toll plaza. It also provides FASTag account management and recharge facilities.

## Features

- User registration and login
- Account management
- Toll plaza selection
- Toll estimation
- Single journey calculation
- Round journey calculation
- Monthly pass calculation
- FASTag registration
- FASTag account management
- FASTag balance checking
- Low balance notification
- FASTag recharge
- Credit card payment option
- Debit card payment option
- CAPTCHA verification

## Technologies Used

- Python
- MySQL
- mysql.connector
- Tabulate

## Main Modules

### User Management
Users can create, log in, view, update and delete their toll account.

### Toll Estimation
Users can select a toll plaza, vehicle type and journey type to calculate the toll cost.

### Journey Types

1. Single Journey
2. Round Journey
3. Monthly Pass

### FASTag Management

The system provides FASTag registration, account management, balance checking and recharge facilities.

### Recharge

FASTag accounts can be recharged using:

- Credit Card
- Debit Card
